# Репозиторий обновлений GlowerOS

Эта ветка — не код, а склад пакетов. Её читает apt на машинах с
установленной системой: в образе прописан источник

    deb [trusted=yes] https://raw.githubusercontent.com/F11htq/Glower/apt/ ./

Файлы `Packages` и `Release` — опись склада, её пересобирает
сборка при каждой метке версии. Править здесь руками нечего.
