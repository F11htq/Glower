# Windows 12 — прототип в браузере

Оболочка в духе тизера Windows 12 (плавающая панель сверху, док снизу) с плавностью и
поведением macOS, максимумом эффекта **Liquid Glass** и работающими приложениями.
Чистые HTML + CSS + JS, без сборки и внешних зависимостей — открывается двойным кликом
по `index.html`.

## Что внутри

**Оболочка**
- Загрузка → экран блокировки (часы, погода) → рабочий стол
- Плавающая верхняя панель: погода, поиск, трей (виджеты, центр управления, батарея, часы)
- Док по центру снизу: увеличение значков под курсором (macOS), индикаторы запущенных
  приложений, «прыжок» при запуске, автоскрытие, контекстное меню
- Меню Пуск: живой поиск (приложения, файлы, параметры, встроенный калькулятор),
  закреплённые, «Рекомендуем»
- Spotlight-поиск (`Win + Space`) с навигацией стрелками
- Центр управления: Wi-Fi, Bluetooth, «Не беспокоить», тема, яркость, громкость,
  плеер «Сейчас играет», быстрые тумблеры стекла
- Панель виджетов + виджеты на рабочем столе (часы, погода, календарь, задачи, система)
- Task View / Mission Control (`Win + Tab`), виртуальные рабочие столы, активный угол
- Уведомления-баннеры, контекстные меню везде, меню питания (блокировка, сон,
  перезагрузка, выключение)

**Ближе к настоящим системам**
- Верхняя панель и виджеты стола уезжают, как только открыто окно; возвращаются
  курсором к верхнему краю (отключается в Параметрах)
- Значки стола: выделение рамкой, перетаскивание с сохранением позиций, `F2`, `Delete`,
  `Enter`, «Выровнять значки»
- Настоящая **Корзина**: удалённое можно восстановить или очистить безвозвратно
- **Snap Assist**: прилепили окно к половине — система предлагает выбрать окно во вторую
- Превью открытых окон при наведении на значок в доке (с закрытием прямо оттуда)
- Диалог **«Выполнить»** (`Win + R`): `notepad`, `calc`, `cmd`, `explorer`, `control`,
  `mspaint`, `taskmgr`…
- Системное меню окна по правому клику на заголовке, **Aero Shake**, `Win + E`,
  `Ctrl + Shift + Esc`, `Alt + F4`, `F5`
- Реальные данные: заряд батареи через Battery API, статус сети через online/offline
- **Мост с вашей настоящей ОС**: перетащите файлы из системного проводника прямо в окно —
  они появятся в виртуальной ФС (картинки открываются в Фото); обратно — «Скачать»
  сохраняет файл на реальный диск (через диалог сохранения, если браузер его поддерживает)

**Панель задач и виджеты**
- При разворачивании окна док превращается в **панель задач Windows**: во всю ширину, с
  прямыми углами; развёрнутое окно останавливается над ней и не заходит под неё
- Когда открыто приложение, часы и трей переезжают в нижнюю панель, туда же встаёт
  кнопка поиска. Верхняя панель больше не выскакивает при наведении курсора вверх
- Виджеты стола **перетаскиваются мышью** (позиция запоминается) и удаляются крестиком;
  доступны часы, погода, календарь, задачи, система и редактируемая заметка. Добавить —
  правым кликом по столу, из Параметров или командой `widget` в терминале
- Системные звуки по умолчанию выключены; отдельно настраиваются звук интерфейса и
  звук уведомлений

**Оконный менеджер**
- Перетаскивание, изменение размера за 8 сторон, разворот, свёртывание «в иконку дока»
- Snap-зоны с призраком: половины, четверти, полный экран
- Мозаика и каскад окон, Alt+Tab, стиль кнопок Windows или macOS

**Приложения (рабочие)**
- **Блокнот** — вкладки, сохранение в ФС, поиск и замена (`Ctrl+F`), выгрузка на диск,
  размер шрифта, перенос, счётчики строк и слов
- **Параметры** — 17 разделов (Система, Персонализация, Док, Анимации,
  Звук, Дисплей, Сеть, Bluetooth, Уведомления, Приложения, Учётные записи, Время,
  Спец. возможности, Конфиденциальность, Обновления, О системе) с живым поиском
- **Проводник** — множественное выделение (`Ctrl`/`Shift`/`Ctrl+A`), копировать/вырезать/
  вставить между папками, перетаскивание файлов в папки и на боковую панель, история
  назад/вперёд, поиск в папке, сортировка, вид «плитка/таблица» с датой, типом и размером,
  свойства, удаление в корзину, импорт и выгрузка настоящих файлов
- **Калькулятор** — с клавиатурой и научными функциями
- **Терминал** — 40+ команд с автодополнением по `Tab` и историей: файлы (`ls -l`, `cd`,
  `pwd`, `cat`, `head`, `tail`, `wc`, `cp`, `mv`, `tree`, `find`, `stat`, `du`, `write`,
  `append`), система (`ps`, `kill`, `sysinfo`, `free`, `env`, `uptime`, `whoami`),
  оболочка (`theme`, `accent #hex`, `glass`, `wall`, `volume`, `widget`, `notify`, `expr`)
- **Paint** — кисти, фигуры, заливка, спрей, отмена, сохранение в Изображения
- **Музыка** — **загрузка своих аудиофайлов** (кнопкой или перетаскиванием в окно),
  библиотека переживает перезагрузку в IndexedDB, перемотка и таймкод, плюс встроенный
  синтезатор на WebAudio; спектр-визуализатор работает и для файлов, и для синтезатора
- **Фотографии**, **Календарь** (события), **Часы** (аналоговые, секундомер, таймер,
  мировые), **Браузер** (внутренняя сеть `dymensity://`), **Задачи**,
  **Диспетчер задач**, **Магазин**

## Кастомизация

Три темы: **Прозрачная** (Liquid Glass во всей красе), **Тёмная** (настоящая тёмная —
непрозрачные поверхности, без бликов и размытия, приглушённые обои) и **Светлая**.

Все настройки материала живут в одном месте — Параметры → Персонализация → *Материал
интерфейса*: размытие, плотность стекла, яркость кромки, насыщенность, скругления и
пресеты (*Максимум стекла*, *Windows 12*, *macOS*, *Матовое*, *Без стекла*).
Также: 12 обоев со слайд-шоу, 10 акцентов + свой цвет, авто-смена темы по времени,
5 системных шрифтов, размер и увеличение дока, состав дока и Пуска, стиль кнопок окна,
скорость анимаций, уменьшение движения, ночной свет, яркость, масштаб интерфейса.

Полезное в Параметрах: **свои обои** из файла, **резервная копия всей системы** —
экспорт настроек, файлов, заметок и задач одним `.json` и восстановление из него,
**автозапуск** выбранных приложений при входе, управление виджетами, панель задач
во всю ширину, часы в панели, раздельные звуки интерфейса и уведомлений.

Все настройки и файлы хранятся в `localStorage`, аудио и свои обои — в IndexedDB.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Win` | Меню Пуск |
| `Win + Space` | Поиск |
| `Win + Tab` | Просмотр задач |
| `Win + ← / →` | Прилипание окна |
| `Win + ↑ / ↓` | Развернуть / свернуть |
| `Win + D` | Свернуть всё |
| `Ctrl + Alt + ← / →` | Виртуальные рабочие столы |
| `Alt + Tab` | Переключение окон |
| `Win + R` | Выполнить |
| `Win + E` | Проводник |
| `Ctrl + Shift + Esc` | Диспетчер задач |
| `Alt + F4` | Закрыть окно |
| `F5` | Обновить рабочий стол |
| `F11` | Полноэкранный режим |
| `Ctrl+C / X / V` | Буфер обмена в Проводнике |
| `Ctrl+F` | Поиск в Блокноте |
| `Esc` | Закрыть панель |

## Структура

```
win12/
├── index.html
├── css/core.css     токены, Liquid Glass, оболочка, окна
├── css/apps.css     стили приложений
├── css/extra.css    значки стола, превью дока, Snap Assist, «Выполнить»
└── js/
    ├── state.js     настройки, обои, виртуальная ФС, звук
    ├── wm.js        оконный менеджер
    ├── apps.js      приложения
    ├── shell.js     док, Пуск, панели, поиск, уведомления
    ├── main.js      запуск
    ├── realism.js   поведение настоящих ОС (стол, корзина, Snap Assist, Win+R)
    ├── fs2.js       Проводник, буфер обмена, импорт/выгрузка настоящих файлов
    └── tweaks.js    панель задач, виджеты стола, терминал, музыка, IndexedDB
```

Лучше всего смотрится в Chrome/Edge/Safari — `backdrop-filter` там аппаратно ускорен.
