# GlowerOS

**GlowerOS** — своя настольная система: плавающая панель сверху, док снизу,
плотные тёмные поверхности, настоящие окна и работающие приложения. Имя, редакция, версия и сборка собраны в одном месте — `js/brand.js`,
фирменный знак лежит в `assets/logo.png` и стоит на экране загрузки, кнопке Пуск,
в «О системе» и во вкладке браузера.
Чистые HTML + CSS + JS: **никакой сборки, бандлеров и зависимостей**. Скачайте папку и
откройте `index.html` двойным кликом — всё заработает сразу, файлы подключаются как есть.

Часть возможностей браузеры разрешают только по `http(s)` (например, диалог сохранения
файла). Если нужно — поднимите локальный сервер: `npm start` или любой другой
статический сервер в этой папке.

## Три режима

Одна и та же оболочка работает на трёх уровнях глубины — от вкладки браузера до
сеанса Linux, где она и есть рабочий стол машины.

**Автономный** — открыли `index.html`, файлы живут в браузере. Ничего не нужно ставить.

**С настоящим диском** — запускается локальный агент, и та же оболочка начинает работать
с реальными файлами вашей машины:

```
node agent/server.mjs           # или npm start
# затем открыть http://localhost:8123
```

Агент раздаёт оболочку и даёт ей то, чего у страницы нет: чтение и запись настоящих
файлов, сведения о машине. Всё, что вы делаете в Проводнике и Блокноте, оказывается на
диске; всё, что появляется в папке снаружи, оболочка подхватывает сама — агент считает
изменения, а оболочка следит за счётчиком. Рабочая папка по умолчанию — `~/GlowerOS`,
меняется ключом `--root`.

Открывать файлы в вашей настоящей системе агент по умолчанию не умеет: это включается
явно ключом `--allow-open`, и тогда в терминале работает `agent open Документы/файл.txt`.

**Границы доверия заданы намеренно**: агент не выходит за пределы рабочей папки, не умеет
запускать программы и не ходит в сеть. Это проверяется тестами, а не обещаниями.

**Как система машины** — агент запускается с ключом `--system`, и оболочка перестаёт быть
страницей про систему:

```
npm run system                  # чтение машины: процессы, программы, громкость, сеть
node agent/server.mjs --system --allow-launch --allow-power   # плюс запуск программ и питание
```

Тогда Диспетчер задач показывает настоящие процессы машины с их PID, загрузкой и памятью
(читается `/proc`, ничего не выдумывается), появляется приложение **«Программы машины»** со
списком из настоящих `.desktop`-файлов, громкость и яркость двигают системные, а «Выключение»
в меню питания действительно выключает компьютер.

Опасное закрыто по умолчанию и открывается только явными ключами: `--allow-launch` для
запуска программ, `--allow-power` для питания, `--allow-open` для открытия файлов в системе.
Произвольные команды агенту недоступны в любом режиме: всё идёт через белый список утилит
без единой строки, уходящей в оболочку.

## Сеанс Linux

Папка `linux/` превращает оболочку в полноценный сеанс рабочего стола:

```
sudo sh linux/install.sh
# затем выйти из сеанса и выбрать GlowerOS на экране входа
```

- `glower-session` — запускает агент и открывает оболочку в режиме киоска: ни адресной
  строки, ни вкладок, ни рамок браузера, только система
- `glower.desktop` — регистрирует GlowerOS в списке сеансов дисплей-менеджера
- `glower-agent.service` — служба systemd с урезанными правами (`ProtectSystem=strict`,
  `NoNewPrivileges`, `MemoryDenyWriteExecute`)
- `install.sh` — проверяет зависимости, раскладывает файлы, ничего не заменяет: ваш прежний
  рабочий стол остаётся на месте, выйти из GlowerOS — выбрать другой сеанс

Что это честно означает: ядро, драйверы, звук и сеть остаются от вашего дистрибутива —
GlowerOS работает поверх них как оболочка, а не переписывает их. Следующий шаг к
самостоятельной системе — собранный образ с этим сеансом внутри.

## Что внутри

**Оболочка**
- Загрузка → экран блокировки (часы, погода) → рабочий стол
- Плавающая верхняя панель: погода, поиск, трей (виджеты, центр управления, батарея, часы)
- Док по центру снизу: увеличение значков под курсором (macOS), индикаторы запущенных
  приложений, «прыжок» при запуске, автоскрытие, контекстное меню
- Меню Пуск: живой поиск (приложения, файлы, параметры, встроенный калькулятор),
  закреплённые, «Рекомендуем»
- Общий поиск (`Super + Space`) с навигацией стрелками
- Центр управления: Wi-Fi, Bluetooth, «Не беспокоить», тема, яркость, громкость,
  плеер «Сейчас играет»
- Панель виджетов + виджеты на рабочем столе (часы, погода, календарь, задачи, система)
- Просмотр задач (`Super + Tab`), виртуальные рабочие столы, активный угол
- Уведомления-баннеры, контекстные меню везде, меню питания (блокировка, сон,
  перезагрузка, выключение)

**Ближе к настоящим системам**
- Верхняя панель и виджеты стола уезжают, как только открыто окно; возвращаются
  курсором к верхнему краю (отключается в Параметрах)
- Значки стола: выделение рамкой, перетаскивание с сохранением позиций, `F2`, `Delete`,
  `Enter`, «Выровнять значки»
- Настоящая **Корзина**: удалённое можно восстановить или очистить безвозвратно
- **Snap Assist**: прилепили окно к половине — система предлагает выбрать окно во вторую
- Превью открытых окон при наведении на значок в доке (с закрытием прямо оттуда)
- Диалог **«Выполнить»** (`Win + R`): `notepad`, `calc`, `cmd`, `explorer`, `control`,
  `mspaint`, `taskmgr`…
- Системное меню окна по правому клику на заголовке, **Aero Shake**, `Win + E`,
  `Ctrl + Shift + Esc`, `Alt + F4`, `F5`
- **Никаких выдуманных данных**: в Параметрах нет несуществующих Bluetooth-устройств,
  Wi-Fi-сетей, VPN и «Защитника». Вместо них — то, что браузер знает на самом деле:
  тип соединения и задержка (Network Information API), заряд и время работы батареи,
  занятое хранилище и его квота, разрешения на камеру/микрофон/геолокацию с настоящими
  запросами, список камер и микрофонов, геймпады, частота обновления экрана замером по
  кадрам, системные `prefers-color-scheme` и `prefers-reduced-motion`, Web Bluetooth с
  настоящим системным диалогом выбора устройства (где он поддерживается)
- **Настоящая погода** через Open-Meteo по названию города, с прогнозом на 5 дней;
  без сети честно помечается как «демо»
- Чего браузер не может — того и нет: раздел «Конфиденциальность» прямо объясняет,
  почему здесь не будет антивируса, брандмауэра и шифрования диска
- **Мост с вашей настоящей ОС**: перетащите файлы из системного проводника прямо в окно —
  они появятся в виртуальной ФС (картинки открываются в Фото); обратно — «Скачать»
  сохраняет файл на реальный диск (через диалог сохранения, если браузер его поддерживает)

**Панель задач и виджеты**
- При разворачивании окна док превращается в **панель задач во всю ширину**: с
  прямыми углами; развёрнутое окно останавливается над ней и не заходит под неё
- Когда открыто приложение, часы и трей переезжают в нижнюю панель, туда же встаёт
  кнопка поиска. Верхняя панель больше не выскакивает при наведении курсора вверх
- Виджеты стола **перетаскиваются мышью** (позиция запоминается) и удаляются крестиком;
  доступны часы, погода, календарь, задачи, система и редактируемая заметка. Добавить —
  правым кликом по столу, из Параметров или командой `widget` в терминале
- Системные звуки по умолчанию выключены; отдельно настраиваются звук интерфейса и
  звук уведомлений

**Учётные записи**
- Несколько профилей: у каждого **свои файлы, обои, настройки, задачи и заметки** —
  данные полностью изолированы
- Настоящий вход по паролю на экране блокировки: хеш SHA-256 через Web Crypto,
  неверный пароль честно отклоняется
- Смена пользователя из Пуска и меню питания, блокировка по `Win + L`
- В Параметрах прямо сказано, чего пароль **не** делает: это блокировка экрана внутри
  прототипа, данные не шифруются и видны через инструменты разработчика

**Системное поведение**
- **Свои диалоги вместо браузерных**: создание, переименование и удаление файлов
  спрашивают в окне системы, а не через `prompt`/`confirm` браузера — с Esc, Enter,
  затемнением фона и красной кнопкой для необратимых действий
- **Центр уведомлений**: баннеры не исчезают бесследно, а копятся в панели с временем
  («только что», «12 мин назад»), удаляются по одному или все сразу; на значке трея
  появляется точка
- **Восстановление сеанса**: после перезагрузки окна открываются там же, где были, с теми
  же размерами и состоянием (отключается в Параметрах → Система)
- **Индикатор громкости и яркости** поверх экрана, как в настоящих системах;
  `Ctrl + Alt + ↑/↓` меняет громкость

**Как в настоящей системе**
- **Файловые ассоциации**: расширение решает, чем открыть файл; в контекстном меню есть
  «Открыть с помощью», а при выборе другого приложения система спрашивает, запомнить ли
  выбор для всех файлов этого типа
- **Свойства** — отдельное окно с размером, датами, содержимым и выбором приложения
  по умолчанию
- **Меню Файл / Правка / Вид** в Блокноте и Paint
- **Диспетчер задач без выдуманных цифр**: реальный FPS замером по кадрам, память
  JavaScript через `performance.memory`, занятое хранилище против настоящей квоты, время
  работы и число DOM-элементов на каждое окно

**Недавнее, ярлыки, печать**
- **Недавние документы**: всё открытое попадает в список — в Пуске он заменил
  «Рекомендуем» и показывает файл, папку и время
- **Списки переходов**: правый клик по значку в доке показывает недавние файлы именно
  этого приложения
- **Ярлыки**: «Создать ярлык на столе» для файла или приложения, значок помечен стрелкой,
  двойной клик ведёт к цели
- **«Свернуть всё»** — узкая полоса в правом углу панели задач, повторное нажатие
  возвращает окна
- **Печать** из Блокнота по `Ctrl+P` — настоящий системный диалог печати браузера
- `Ctrl+Shift+N` — новая папка в Проводнике

**Проводник**
- **Вкладки**: `Ctrl+T` открывает новую, `Ctrl+W` закрывает, правый клик по вкладке —
  открыть её в отдельном окне; последняя закрытая вкладка закрывает окно
- **Адресная строка**: `Ctrl+L` или двойной клик по пути превращает крошки в поле ввода —
  введите `/Документы/Проекты` и попадёте туда
- **Поиск по всему компьютеру**: кнопка «Везде» ищет во всех папках рекурсивно и
  показывает, где что лежит
- **Сортировка кликом по заголовку** столбца в табличном виде

**Файловые операции**
- **Разрешение конфликтов** при вставке: если файл уже есть — «Заменить», «Сохранить оба»
  (второй получит номер) или «Пропустить», с флажком «применить ко всем оставшимся»
  и размером и датой существующего файла для сравнения
- **Переименование прямо на значке** по `F2` — поле появляется на месте подписи, имя без
  расширения выделяется автоматически, `Enter` сохраняет, `Esc` отменяет
- `Alt + Enter` — свойства выделенного
- **Перетаскивание файла на значок в доке** открывает его этим приложением

**Оконный менеджер**
- Перетаскивание, изменение размера за 8 сторон, разворот, свёртывание «в иконку дока»
- Snap-зоны с призраком: половины, четверти, полный экран
- Мозаика и каскад окон, переключение окон по `Alt + \``, кнопки окна прямые или круглые

**Приложения (рабочие)**
- **Блокнот** — вкладки, сохранение в ФС, поиск и замена (`Ctrl+F`), выгрузка на диск,
  размер шрифта, перенос, счётчики строк и слов
- **Параметры** — 17 разделов с живым поиском; «Фокусировка» действительно включает
  «Не беспокоить» на выбранное время с обратным отсчётом, «Экономия ресурсов» реально
  снимает размытие и ускоряет анимации
- **Проводник** — множественное выделение (`Ctrl`/`Shift`/`Ctrl+A`), копировать/вырезать/
  вставить между папками, перетаскивание файлов в папки и на боковую панель, история
  назад/вперёд, поиск в папке, сортировка, вид «плитка/таблица» с датой, типом и размером,
  свойства, удаление в корзину, импорт и выгрузка настоящих файлов
- **Калькулятор** — с клавиатурой и научными функциями
- **Терминал** — 40+ команд с автодополнением по `Tab` и историей: файлы (`ls -l`, `cd`,
  `pwd`, `cat`, `head`, `tail`, `wc`, `cp`, `mv`, `tree`, `find`, `stat`, `du`, `write`,
  `append`), система (`ps`, `kill`, `sysinfo`, `free`, `env`, `uptime`, `whoami`),
  оболочка (`theme`, `accent #hex`, `glass`, `wall`, `volume`, `widget`, `notify`, `expr`)
- **Paint** — кисти, фигуры, заливка, спрей, отмена, сохранение в Изображения
- **Музыка** — **загрузка своих аудиофайлов** (кнопкой или перетаскиванием в окно),
  библиотека переживает перезагрузку в IndexedDB, перемотка и таймкод, плюс встроенный
  синтезатор на WebAudio; спектр-визуализатор работает и для файлов, и для синтезатора
- **Фотографии**, **Календарь** (события), **Часы** (аналоговые, секундомер, таймер,
  мировые), **Браузер** (внутренняя сеть `dymensity://`), **Задачи**, **Диспетчер задач**
- **Магазин** — не витрина, а настоящая установка: приложения из каталога появляются в
  Пуске и доке, запускаются как системные, удаляются вместе с данными и переживают
  перезагрузку. В каталоге: **Помидор** (таймер 25/5 с циклами), **2048** (играбельная,
  с рекордом и свайпами), **Конвертер величин**, **Палитра** (генератор схем, цвет можно
  сделать акцентом системы)

**Свои приложения**

Приложение — это `.json`-пакет: `id`, `name`, `glyph`, размеры окна и `code` на
JavaScript. Магазин создаёт рабочую заготовку прямо в Документах и открывает её в
Блокноте; готовый пакет ставится из виртуальной ФС или с реального диска. Код получает
объект окна и системный API (`el`, `KV`, `FS`, `Shell`, `WM`, `S`) — то есть может
рисовать интерфейс, читать и писать файлы, показывать уведомления.

Пакет исполняется как обычный код страницы, поэтому ставьте только то, что читали сами —
Магазин прямо предупреждает об этом.

## Загрузочный образ

```
sudo apt install debootstrap squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools
sudo bash linux/mkiso.sh --out glower.iso           # ~1,4 ГБ, 20–30 минут
sudo dd if=glower.iso of=/dev/sdX bs=4M status=progress   # на флешку
```

### Как записать образ на флешку

Образ гибридный: он рассчитан на побайтную запись, и подменять в нём загрузчик
не нужно.

* **Windows, Rufus.** Выбрать образ и записать в режиме **DD** («Запись
  DD-образа»). Rufus иногда предлагает скачать новую версию GRUB — соглашаться
  не обязательно: в режиме DD его вопрос ни на что не влияет, файл пишется как
  есть. В режиме «ISO» Rufus перекладывает файлы и ставит свой загрузчик — так
  наш образ грузиться не обязан.
* **Windows, другие программы.** Подойдёт любая, умеющая писать образ побайтно
  (например, balenaEtcher — он иначе и не умеет).
* **Linux/macOS.** `sudo dd if=glower.iso of=/dev/sdX bs=4M status=progress`.

### Если экран гаснет сразу после загрузчика

Так ведут себя старые машины, где ядро не может взять на себя управление
видеокартой. В меню загрузки (оно показывается восемь секунд) есть пункт
**«Установка GlowerOS · безопасная графика (для старых машин)»** — он не даёт
ядру трогать видеокарту, и изображение идёт простым способом, который понимает
почти любое железо. Есть и пункт **«с сообщениями системы»**: он ничего не
скрывает, и по последним строкам видно, где именно всё встало.

В таком режиме рабочий стол показывается через X-сервер, а не через Wayland:
Wayland на машине без управления видеокартой не поднимется вовсе, а X-сервер
работает. Оболочка при этом та же самая, окнами распоряжается openbox, список
окон и их состояния система читает через X, а терминал берётся тот, который
под X работает.

**Что проверено на живой машине** (`bash test/vm-старая-машина.sh glower.iso`):
система грузится без управления видеокартой, рабочий стол показывает X-сервер,
оболочку — своя программа на WebKit, окна ведёт оконный менеджер, панель задач
их видит, терминал открывается.

Ограничение этого режима, о котором честно: под X-сервером панель задач может
закрываться окнами программ — полосу под неё там отводить некому. На машинах,
где ядро видеокартой управляет, всё как обычно: панель место за собой держит.

Образ загружается сам: GRUB → ядро → systemd → оконный сервер labwc → GlowerOS.
Никакого рабочего стола Ubuntu под низом — только система. Из живого образа систему
можно установить на диск (см. ниже).
Скрипт не собирает образ втихую: если нет загрузочной записи, он падает с ошибкой,
а не выдаёт красивый файл, который не грузится.

**Что проверено на живой загрузке** (qemu, снятые кадры экрана): образ грузится,
сеанс поднимается, оболочка стартует, находит машину через агент, показывает
начальную настройку и работает с настоящим диском `/home/glower/GlowerOS`.

## Сеть

Проводная сеть и Wi-Fi ведутся настоящим NetworkManager. В настройках, в разделе
«Сеть и Интернет», система показывает свои сетевые устройства, состояние
подключения, а для Wi-Fi — список сетей вокруг с уровнем сигнала и замком у
защищённых, подключение по паролю, отключение и выключатель радио. Пароль уходит
к `nmcli` отдельным аргументом и обратно в оболочку не возвращается.

**Найдено живой проверкой и исправлено** (снимок трафика виртуальной машины
показывал ноль пакетов — гость не отправлял даже DHCP-запроса):

- Ubuntu настраивает NetworkManager так, что он ведёт **только Wi-Fi и модемы**,
  а проводную сеть оставляет netplan и systemd-networkd, которых в нашей системе
  нет. Кабель был воткнут, а адрес никто не запрашивал. Теперь NetworkManager
  ведёт все устройства и сам пишет адреса DNS: `systemd-resolved` в образ не входит.
- В службе сеанса строка `Environment=GLOWER_FLAGS=...` стояла **без кавычек**, и
  systemd молча оставлял от неё только первое слово. Из-за этого в системе не
  работали ни выключение, ни установка на диск, ни управление сетями — ключи
  просто не доходили до агента.

Проверено на загруженной системе: агент отвечает снаружи через проброшенный порт
(значит, DHCP прошёл), `nmcli` видит `ens3` подключённым, в снимке трафика есть
DHCP, ARP, DNS и TCP, а запрос возможностей показывает разрешённые питание,
установку и сети.

## Программы Linux

Рядом со своими приложениями система ставит настоящие программы из репозиториев
Ubuntu. В магазине для этого есть вкладка **«Программы Linux»**: поиск по
репозиториям, версия и объём у каждой находки, установка и удаление с видимым
ходом работы. Установленная программа появляется в «Программах машины» и
запускается как обычная.

Всё идёт через `apt`, и правила те же, что у остального системного слоя: никаких
строк, уходящих в оболочку, имя пакета проверяется по образцу (ключ вместо имени
не подставить), установка требует ключа `--allow-packages`, за раз идёт одна
работа. Отдельно закрыто удаление того, без чего система перестанет работать:
ядро, systemd, apt, sudo, nodejs, chromium, cage, сеть, загрузчик.

Проверено на живой машине: поиск находит настоящие пакеты с версиями и размерами,
установка и удаление проходят до конца, а попытки снести systemd, nodejs или
chromium отклоняются с объяснением.

### Программа, скачанная файлом

Скачанный `.deb` ставится двойным щелчком, как в любой обычной системе. Система
сама читает файл и показывает, что за программа к ней просится: имя, версию,
размер, сколько займёт на диске, — и спрашивает согласия. Молча чужой файл из
интернета не ставится никогда.

Ставит apt, а не голый dpkg: недостающие зависимости подтягиваются сами, и
установка не обрывается на середине из-за нехватки библиотеки.

Так же открываются `.flatpakref` со страницы Flathub (ставит flatpak) и
программы одним файлом `.AppImage` — эти не ставятся вовсе: система делает файл
исполняемым и запускает, тоже спросив.

Ставится только то, что лежит там, куда человек кладёт скачанное: домашняя
папка, `/tmp`, съёмные носители. Пакет для другого железа система назовёт
прямо, а не свалится на середине.

## Установка на диск

Живой образ работает из памяти и всё забывает при выключении. Мастер **«Установка
GlowerOS»** переносит систему на диск: размечает его (GPT, раздел загрузчика BIOS,
раздел EFI, корень ext4), распаковывает ту же самую систему, прописывает fstab по UUID
и ставит загрузчик — для BIOS и для UEFI сразу. После перезагрузки машина грузится
с диска и запоминает всё: учётную запись, настройки, файлы, закладки браузера.

Опасную часть делает не оболочка, а сценарий `linux/glower-install`, и делает строго:
диск обязан быть назван явно, носитель с которого запущена живая система отвергается,
без ключа `--yes` ничего не пишется, а `--dry-run` только показывает план. Агент
пускает установку лишь при ключе `--allow-install` и сверяет имя диска со списком
настоящих дисков машины.

**Что проверено по-настоящему** (`sudo bash test/install.sh glower.iso`): установка
на пустой диск проходит целиком, разделы и файловые системы создаются, загрузчик
пишется в начало диска, меню ищет корень **по UUID**, система и оболочка переносятся,
пароль и имя машины записываются. Отдельно проверена загрузка установленного диска
в qemu: машина стартует с него и показывает начальную настройку, а после работы
на диске остаются данные сеанса — то есть система действительно перестала быть живой.

Ошибка, найденная этой проверкой и исправленная: `grub-mkconfig` записывал в меню имя
устройства машины-установщика (`/dev/loop0p3`), и после перезагрузки система
останавливалась в initramfs. Теперь корень в меню всегда переписывается на UUID,
а установка обрывается с понятной ошибкой, если этого не вышло.

**Меню загрузки** содержит три пункта: обычный запуск, **«безопасная графика»**
(для машин, где драйвер экрана ядра не заводится: система поднимется через X-сервер) и подробный запуск с видимыми сообщениями ядра.
Первая консоль принадлежит оболочке, со второй по шестую (`Ctrl+Alt+F2`) — обычный
вход для разбора: пользователь `glower`, без пароля, `sudo` без пароля.

Если оболочка не поднялась, система не мигает курсором: служба останавливается после
трёх попыток и оставляет на экране список того, что ей известно — есть ли графический
узел, найден ли браузер, где журнал `/var/log/glower-session.log`.

**Что честно не проверено**: работа мыши и клавиатуры внутри эмулятора без
видеоускорения. Полноэкранное размытие там рисуется процессором, и интерфейс
перестаёт отвечать. Система это предвидит — сеанс проверяет наличие `/dev/dri/renderD*`
и без видеоядра сразу просит оболочку работать без размытия, — но подтвердить
отзывчивость можно только на машине с настоящей видеокартой: с флешки или в
виртуальной машине с включённым ускорением.

## Первый запуск

При первом включении система встречает начальной настройкой — как любая система при первом
включении, но короче и без вранья: язык, раскладки, город для погоды, имя и аватар,
пароль (не обязателен), тема, акцент и обои. Отдельная страница честно говорит, что
система знает о вас: всё остаётся на этой машине, единственный запрос наружу — погода,
сбора статистики и рекламных идентификаторов нет вовсе.

После настройки — приветственная анимация с именем пользователя, и рабочий стол.
Пройти настройку заново можно в Параметрах → Система.

## Языки и раскладки

**Язык интерфейса** переключается в Параметрах → *Время и язык*: русский и английский.
Русский — исходный, английский собран словарём по точному совпадению строки, и Параметры
честно пишут, сколько строк переведено: то, чего в словаре нет, остаётся по-русски.
Вместе с языком меняются формат даты и времени.

**Раскладка клавиатуры** живёт в трее рядом с часами: `ENG`, `РУС`, `DEU`.
Список раскладок в Параметрах спрятан под стрелку и раскрывается щелчком, как в настоящей
системе — открытое состояние запоминается.
Переключается кликом по индикатору или `Alt + Shift`. Раскладка применяется только к
полям ввода внутри системы — страница не может и не пытается менять раскладку всей
вашей машины, о чём Параметры говорят прямо. По умолчанию стоит латиница, чтобы система
ничего не меняла в вашем наборе, пока вы сами не попросите.

## Что срабатывает само

- **Будильники** с днями недели — отдельная вкладка в «Часах»; разовый выключается после звонка
- **Напоминания календаря**: у события есть время, и в эту минуту приходит уведомление
- **Автоблокировка** экрана после заданного бездействия (считается настоящий ввод)
- **Экран блокировки** показывает уведомления и то, что играет, с управлением плеером;
  содержимое уведомлений можно скрыть, а рабочий стол за замком не виден
- **Поиск в Проводнике** заглядывает внутрь текстовых файлов и показывает совпавший кусок

Раздел Параметров **«Клавиатура»** перечисляет сочетания системы и честно говорит, какие
из них забирает себе браузер: `Alt + Tab`, `Alt + F4`, `F5`, `F11`, `Ctrl + T`. Перехватить
их со стороны страницы нечем, поэтому окна системы переключаются по `Alt + \``.

## Кастомизация

Две темы: **Тёмная** (по умолчанию — плотные поверхности, приглушённые обои) и
**Светлая**. Прозрачных поверхностей в системе нет: текст сквозь узор читается хуже,
а размытие каждого окна отнимает силы у слабой машины.

Форма поверхностей живёт в Параметрах → Персонализация: скругление панелей и окон.
Также: 12 обоев со слайд-шоу, 10 акцентов + свой цвет, авто-смена темы по времени,
5 системных шрифтов, размер значков дока, состав дока и Пуска, форма кнопок окна,
скорость анимаций, уменьшение движения, ночной свет, яркость, масштаб интерфейса.

Полезное в Параметрах: **свои обои** из файла, **резервная копия всей системы** —
экспорт настроек, файлов, заметок и задач одним `.json` и восстановление из него,
**автозапуск** выбранных приложений при входе, управление виджетами, панель задач
во всю ширину, часы в панели, раздельные звуки интерфейса и уведомлений.

Все настройки и файлы хранятся в `localStorage`, аудио и свои обои — в IndexedDB.

## Структура и разработка

Правится напрямую: сохранили файл — обновили страницу. Порядок подключения скриптов
в `index.html` важен: `brand.js` задаёт имя системы, `ns.js` читает профиль до всего остального, `state.js` поднимает
настройки и файловую систему, дальнейшие файлы дополняют и переопределяют уже готовые
части оболочки.

## Тесты

```
npm i             # один раз, ставит playwright
npm test          # 95 проверок оболочки в настоящем браузере
npm run test:native   # 14 проверок связки с агентом и настоящим диском
npm run test:linux    # 17 проверок работы оболочки как системы машины
```

Второй набор поднимает агент во временной папке, открывает оболочку и убеждается, что
файл с диска виден внутри системы, что созданное в оболочке появляется на диске, что
переименование и удаление доходят до файловой системы, что правка папки снаружи
подхватывается сама, и что за пределы рабочей папки агента не выпускают, а файлы в
системе он без явного ключа не открывает.

Тесты гоняют реальные сценарии: загрузку и разблокировку, открытие файла с рабочего
стола, превращение дока в панель задач, запуск всех приложений, вычисление в
калькуляторе, команды терминала, создание и удаление файла с попаданием в корзину,
установку приложения из каталога и своего пакета, переключение тем, вход по паролю,
изоляцию профилей, смену раскладки с настоящей транслитерацией и переключение языка
интерфейса на английский и обратно. Заодно падают, если в консоли появилась хоть одна ошибка JS.

Лучше всего смотрится в Chrome/Edge/Safari — `backdrop-filter` там аппаратно ускорен.
