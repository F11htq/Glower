# Опрос чужих окон

`glower-toplevels` — маленькая программа: спрашивает у оконного сервера,
какие сейчас открыты чужие окна и в каком они состоянии, печатает JSON и
заканчивается.

Зачем своя, если есть `wlrctl`: `wlrctl` отвечает только «да/нет» на один
вопрос за запуск, а про развёрнутое окно отвечает неверно — проверено на
labwc, где развёрнутое окно он называет неразвёрнутым. Своя программа
читает состояния прямо из протокола и за один запуск отдаёт всё сразу:
имя программы, заголовок, развёрнуто, свёрнуто, в работе, во весь экран.

Файл `wlr-foreign-toplevel-management-unstable-v1.xml` — описание
протокола wlroots (лицензия MIT), взято из исходников wlr-protocols.
Из него `wayland-scanner` создаёт код при сборке образа.
